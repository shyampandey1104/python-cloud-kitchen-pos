# 🍲 Python Cloud Kitchen & Multi-Brand Restaurant POS Engine

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A high-throughput **Restaurant & Cloud Kitchen POS Engine** in Python. Features digital Kitchen Order Tickets (KOT) station routing, multi-brand catalog management, item preparation modifier notes, and statutory 5% restaurant GST tax billing settlements.

---

## ⚡ Highlights
- 🍳 **KOT Generation**: Instant kitchen order ticket dispatch grouped by station.
- 🏷️ **Multi-Brand Routing**: Run multiple virtual kitchen brands from a single inventory.
- 🧾 **Bill Settlements**: Discount calculations with dual CGST / SGST split.
- 🧪 **Pytest Coverage**: Unit tests included.
